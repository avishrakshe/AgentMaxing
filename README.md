# Crier

An autonomous WhatsApp community agent: watches X, triages what matters, drafts a WhatsApp caption + branded poster, waits for admin approval, and publishes. Pays for its own X data via x402 from its agent wallet.

Built on the [agentmaxxin](https://www.npmjs.com/package/agentmaxxin) starter (Next.js + Gemini + x402 agent wallet on Base Sepolia).
